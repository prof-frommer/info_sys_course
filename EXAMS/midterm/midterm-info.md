# Information Systems Midterm Exam Info
The midterm exam will be in class on **Th 10/8**.  

It **covers all course content from class up through Tu 10/6** except it **won't include any SQL in Python** that we may cover on Tuesday

It consists of two portions. You will have up to around half the class period to complete the first portion and move on to the second part.

##  Part I - Written Portion
10-20 short answer written questions on:
- Terminology
- Pandas/python commands for data processing/cleaning/analysis
- Basic webscraping code and info
- Database fundamentals – ER diagrams, normal forms, joins, etc.
- Access including possibly questions based on Access screen shots
- SQL  

Short answer could include T/F, multiple choice, fill-in-the-blank, matching, short free response (e.g. write 1-2 lines of code or a 1-2 sentence answer), and others.

**You may bring 1 cheat sheet that is an 8.5” x 11” sheet of paper with notes on one-side only, hand-written or typed by you, no copying and pasting from others.**  You will perform much better on the exam if you study and write a cheat sheet instead of expecting that writing a cheat sheet can serve as a substitute for studying.

## Part II - Computing Portion.

This portion will have one or both of these sub-parts:
1) data analysis problem, similar to baby names, drug deaths, Montreal bike paths problems
2) database problem using Access and possibly SQL like Tutorial B or HW 6 Part I
 
**For this portion, you may use** your own class notes (including the cheat sheet from Part I), your own class homeworks, your own class quizzes, any materials on our course repo and Canvas site, your course textbooks, and any materials handed out in class. **No other materials are allowed**, including but not limited to Internet searches, AI, materials from prior years of this course, etc.  

**No collaboration with anyone is allowed.**
