## Midterm grades

Based on:
- HWs 1 -5 (110 points total)
- Quizzes 1 - 3 (30 points total)
- Midterm Exam (100 points)

`Course Grade % = 14% * HW + 30% * Quiz + 56% * Midterm Exam`  

roughly consistent with final grade percentages.

Standard cutoffs used:  

```  

grade cutoffs	

0	F

60	D

70	C-

73	C

77	C+

80	B-

83	B

87	B+

90	A-

93	A

97	H

```
